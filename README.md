# ARTEMIS-Senior-Project
ARTEMIS is a veterinary web application centered on an interactive 3D animal model that lets clinicians visually mark and explain injuries, symptoms, and areas of concern. Findings connect to patient records and clinical notes through a Python backend and Supabase.


#############################################################
# M1_#D_Model 3D Model (React Three Fiber)
IN M1_3D_Model Folder is A small React / Vite / React Three Fiber proof of concept using the existing German shepherd GLB. No backend or clinical functionality is included.
The Folder is a 3D viewer protype which will be an example for what we plan to have the viewer look like.
Requires Vite Dependecy

To install Vite:
npm.cmd install 

Install the project's dependencies once:

npm install
npm run dev
